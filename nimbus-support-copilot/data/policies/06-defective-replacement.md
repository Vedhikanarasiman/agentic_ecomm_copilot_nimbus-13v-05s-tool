# Defective Item Replacement Process

If a device fails within 30 days of delivery due to a manufacturing defect (not accidental damage), the customer is entitled to a free replacement or full refund, customer's choice — this overrides the standard restocking fee and opened-item fee rules.

Process:
1. Customer describes the defect; agent checks it's a functional issue, not cosmetic or accidental.
2. If order is within 30 days of delivery and status is "delivered": approve replacement, generate prepaid return label for the defective unit.
3. If order is between 31-365 days: route to Standard Manufacturer Warranty instead, not this faster path.
4. If the defect description sounds like physical/accidental damage: do not approve automatically — escalate to a technician for photo-based inspection.
