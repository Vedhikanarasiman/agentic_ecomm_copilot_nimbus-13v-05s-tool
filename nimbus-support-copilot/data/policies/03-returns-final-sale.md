# Final Sale Items

Items marked "Final Sale" at checkout — typically clearance stock, open-box deals, and demo units — are not eligible for return or refund except in case of manufacturer defect confirmed by a Nimbus technician.

Final sale status is shown on the product page and order confirmation email. If a customer disputes final-sale status, check the order record: the "category" tag alone does not indicate final-sale status — this must be cross-checked against the original listing, which is not available to this support system. Escalate disputes of final-sale classification to a human agent rather than guessing.
