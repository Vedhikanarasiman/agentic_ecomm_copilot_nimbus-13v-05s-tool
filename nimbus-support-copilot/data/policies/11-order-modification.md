# Order Modification Policy (Address, Item Changes)

Shipping address changes are only possible while an order is in "processing" status, and only if the new address is within the same country as the original (international re-routing is not supported). Item or quantity changes are not supported after an order is placed — the customer must cancel (if still "processing") and place a new order.

Once status is "shipped," no modifications of any kind are possible; the package will deliver to the original address.
